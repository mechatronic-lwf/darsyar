# واژگان تخصصی انگلیسی

وب‌اپ آموزشی مستقل (HTML/CSS/JS بدون هیچ وابستگی) برای یادگیری واژگان و جملات تخصصی مهندسی برق و مکاترونیک.

- فایل اصلی: [index.html](index.html)
- اجرا: کافی است فایل را در مرورگر باز کنید؛ بدون نیاز به سرور یا اینترنت.
- نسخه آنلاین: https://mechatronic-lwf.github.io/english-learning/

## قابلیت‌ها
- ۹۴ کارت آموزشی (شماره‌های ۱ تا ۹۴، مطابق منبع اصلی + دو واژه تکمیلی)
- تلفظ انگلیسی با Web Speech API (انتخاب لهجه، سرعت و صدا — حالت خودکار شفاف‌ترین صدا را انتخاب می‌کند)
- تمرین تلفظ با ضبط صدا و مقایسه تقریبی (در مرورگرهای دارای Speech Recognition)
- حالت مرور فلش‌کارت و حالت آزمون
- جست‌وجو و فیلتر (دسته‌بندی موضوعی، یادگرفته/یادنگرفته، کلمه/جمله)
- ذخیره پیشرفت در localStorage
