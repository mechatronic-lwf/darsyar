# درس‌یار

سامانه آموزشی تحت وب برای دانش‌آموزان: انتخاب درس → انتخاب پودمان → یادگیری، تلفظ، مرور و آزمون.

- نسخه آنلاین: https://mechatronic-lwf.github.io/darsyar/

## ساختار

| فایل | نقش |
|---|---|
| `index.html` | صفحه اصلی (درس‌های من، ادامه یادگیری، جست‌وجو، تنظیمات) |
| `danesh-fani.html` | صفحه پودمان‌های درس دانش فنی |
| `podman-1.html` | صفحه آموزش واژگان پودمان اول (کارت‌ها، تلفظ، مرور و آزمون) |
| `darsyar-data.js` | ساختار داده درس‌ها و پودمان‌ها + توابع پیشرفت |
| `darsyar.css` | استایل مشترک صفحات اصلی و درس |
| `fonts/` | فونت وزیرمتن (هاست محلی، بدون وابستگی خارجی) |

## افزودن درس یا پودمان جدید

فقط ساختار `DARSYAR.courses` در `darsyar-data.js` گسترش داده می‌شود؛ صفحه اصلی و صفحه درس از روی داده رندر می‌شوند و نیازی به بازنویسی ندارند.

هر پودمان آماده باید `status: "ready"`، مسیر `page` و `progressKey` مخصوص خودش در localStorage داشته باشد.

## محدودیت‌ها

- پیشرفت دانش‌آموز فقط در مرورگر (localStorage) ذخیره می‌شود؛ حساب کاربری و همگام‌سازی سرور در نسخه‌های آینده.
- تلفظ به صداهای انگلیسی نصب‌شده روی دستگاه وابسته است.
